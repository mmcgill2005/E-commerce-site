RePlay – Sports Gear Marketplace Prototype
Project Overview

RePlay is a prototype e-commerce website designed to combine new and resale sports gear into one user-friendly platform. The site includes product browsing, filtering, resale marketplace features, cart functionality, and a simulated checkout process.

Features
Browse sports products and resale items
Filter products by sport, gender, and condition
Add items to cart
Dynamic cart total calculations
Simulated checkout workflow
Resale marketplace item submission form

Product and cart data are managed using JavaScript and browser local storage.
